# 历史实验归档与清理记录

2026-10-31，用户明确授权只保留当前评估和论文用到的模型，将未采用数据归档并删除旧检查点，以及删除`tests/`回归测试代码。

- 当前正式数据与14个选定模型：`../../results/paper_current/`。
- `results/`：原`results/`下的历史目录，保留全部非检查点文件，包括未采用结果、失败样本、配置、日志、冻结计划及模型选择证据。
- `cleanup_plan.json`：操作前的精确复制、归档和删除目标；不是通用通配符删除方案。
- `historical_files.csv`：历史非检查点文件原位置、归档位置和SHA256。
- `deleted_checkpoints.csv`：被删除的21726个原位置检查点。选定14个已在当前目录复制并核验，故原位置副本也在删除清单内。
- `regression_tests_backup.zip`：已逐文件核验内容哈希的测试代码恢复包；工作目录`tests/`被删除。
- `completion.json`：实际操作完成计数与核验状态。

未采用实验的checkpoint本体已按授权删除，不能再从这些旧模型继续训练或重新评估；旧评估结果和记录仍完整保留。数据集、仿真/算法代码、实验评估脚本、论文和图片不在本次删除范围内。

原清单中的路径不会改写。阅读旧记录时，将其原`results/`前缀映射到本目录的`results/`；选定模型的新位置以当前目录`manifest.json`为准。原一次性脚本不保证直接适配搬迁后的路径，当前核验与绘图命令见正式数据目录README。
