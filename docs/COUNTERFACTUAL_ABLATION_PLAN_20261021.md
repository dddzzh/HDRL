# 共享队列下Deadline反事实反馈：消融设计

日期：2026-10-21。状态：设计稿，未实现新开关、未生成启动配置、未启动训练或评估。本文不替换已有结果、主场景表或论文源文件。

## 研究问题与现有证据

- Question：频率控制采用满频增量代价、并把共享队列中的损失分配给责任来源，是否比本工作流结果反馈或均匀责任分配更有利于联合约束下的节能？
- Type：受控学习实验；主张仅限下层Deadline反馈，不同时检验可靠性反馈、上层Deadline头或整个拉格朗日机制。
- Hypotheses：H1，跨工作流责任归因优于把同一增量代价给受影响工作流自身；H2，责任权重优于等权分配；H3，扣除满频下仍存在的迟到有助于避免下层承担全部端到端迟到。
- Current evidence：现有HEFT/固定频率/去头对照检验结构差异；共享队列单元测试验证一项实现行为，均不构成H1—H3的学习效果证据。
- Missing evidence：匹配网络、训练输入、预算与选模规则的独立重训对照；多训练随机种子；真实队列影响诊断。
- Support：在相近ESP/Rel下能耗更低，或在相近能耗下ESP更高，且差异跨训练重复保持；外部责任与队列传播诊断支持相应解释。
- Falsification：控制组相当或更好；差异只出现在个别训练重复；几乎没有非零增量/外部责任。此时保留结果并收缩对应贡献，不继续筛选种子制造差距。
- Minimal next action：实现反馈入口与守恒测试，冻结配置差异和工作负载种子表；仅用验证池做信号及输入预检，再按冻结方案正式训练。

## 1. 四个版本：把“怎么算”和“给谁”分开

对同一条已完成轨迹，令 `ell_v = max(M_v / D_v - 1, 0)`，其中M为工作流响应时间、D为相对Deadline。

`d_v = clip(ell_v - ell_v_all_rho1, 0, 1)` 为当前方法的满频增量代价。满频回放固定服务器放置、每台服务器任务顺序、通信和决策释放时间。

`Delta_uv = max(ell_v - ell_v_restore_u, 0)` 为仅恢复来源工作流u至满频时，受影响工作流v的迟到减少量。该量用于权重，不直接无条件累加为总惩罚。

| ID | 工作流级SAC责任代价G | 下层Deadline乘子输入 | 唯一处理因素 |
|---|---|---|---|
| CF-Full | 现有按Delta列归一化的来源责任分配 | 原始受影响者向量d | 当前完整方法 |
| CF-Self | G_v=d_v | 与Full相同定义的d | 取消跨工作流来源归因，把增量代价反馈给受影响者自身 |
| CF-Uniform | 总量C=sum(d)，平均给集合S中的每个来源 | 与Full相同定义的d | 用等权代替反事实边际权重 |
| Raw-Self | G_v=clip(ell_v,0,1) | 同样的原始迟到向量clip(ell,0,1) | 在Self反馈下，不扣除满频下仍存在的迟到 |

CF-Uniform的集合S提前固定为本批确实有正执行时间增量（>1e-8秒）的降频工作流，不按是否迟到、是否有Delta或测试成败筛选。G_u=C/|S|（u属于S），其他为0。所有正总成本但S为空的轨迹必须记录并检查数值/输入一致性，不能静默丢弃成本。

Full保留当前零边际时按来源累计执行增量分配的回退规则。正式数据必须有完整task_plans；缺计划不能悄悄进入legacy近似回退。

四组内部都沿用相同任务级分摊：按该工作流各任务的正执行时间增量分摊G；分母为零时在本工作流动作中均分。即时节能项和局部时间成本项保留原实现。因此CF-Self是“本工作流结果反馈”，不等于“只保留即时任务耗时惩罚”。

### 对照分别能回答什么

1. Full vs CF-Self：相同增量定义下，识别并反馈共享队列责任来源是否有效。
2. Full vs CF-Uniform：相同总成本下，差异化来源权重是否优于等权来源分配。
3. CF-Self vs Raw-Self：固定Self分配后，满频增量定义是否优于直接承担自身全部迟到。
4. Full vs Raw-Self：完整反馈方案与端到端自身结果反馈的整体差异；不能把差异全部归给单一因素。

前三个CF版本对同一固定轨迹的总代价和乘子输入须相同；不能要求不同已训练策略产生相同轨迹、乘子数值或累计成本。Raw-Self有意改变代价及对应乘子统计，不宣称与CF版本等总量。其预算保持数值相同且两种成本均截断至[0,1]，结论限于现有预算下的两套反馈定义，不宣称各自最优调参后的普遍优劣。

## 2. 固定训练设置

- 基准：`configs/v3_sm_74_legacy_train.json`。74台=56 edge+18 cloud；Small科学工作流。SM不指Medium工作流。
- 每轮20工作流；训练到达率0.1/s；Medium Deadline；原训练生成器`cai_2025_heft`；1200轮。
- 全部从头联合训练完整上层与SAC；不冻结上层，不删除Deadline头，不固定rho=1，不从已训练Full热启动控制组。
- 上层三Q网络、下层SAC网络、所有学习率、训练更新次数、奖励归一化、即时时间惩罚、四个乘子初始化/更新公式/上限/预算、rho硬件与能效下限、可靠性门槛及物理模型一致。
- 可靠性代价与可靠性乘子均不作为本轮处理因素。
- 正式重复：训练随机种子42、43、44，每种子四版本，合计12次训练、14400轮。为消除历史代码版本差异，默认Full也按同一冻结代码重训；旧Full仅作回归参考。
- 显式冻结每轮工作负载seed表，四版本按训练重复成对使用相同输入；工作负载随机源与模型探索/采样随机源分离。不能仅凭总seed相同就声称每轮输入已配对。
- 每个进程Torch线程1；后续启动并发取决于当时任务和用户资源偏好，本设计不授权停止其他进程。

## 3. 验证选模与失败规则

- 沿用每20轮双验证：542000—542019、642000—642019；验证输入、生成方式和初始化规则四版本一致。

## 5. 实现与预检门槛

正式启动前只在验证池预检，不读取测试结果来决定对照定义。

1. 原Full路径回归：相同固定轨迹的d、G和SAC任务代价不变；未配置新入口时默认行为不变。
2. 同轨迹守恒：前三个CF版本sum(G)=sum(d)，任务级代价总和等于其工作流G；乘子输入保持受影响者向量d，不能误换为来源G。
3. 构造A拖慢B且C也降频但无关的案例：Full追责A；Self给B；Uniform在预先定义的S={A,C}等分。这样可区分全部分配规则。
4. 构造满频仍迟到的案例：Raw-Self含基础迟到，CF-Self仅含可由降频移除的增量。
5. 检查多来源共同影响、零边际回退、无降频、无迟到、零执行增量、DAG分支、多个服务器和决策释放时间约束。
6. 在验证池5个预定seed、基准/较高到达率下记录d非零比例、外部责任非零比例、等待与并发。冻结预检名单并保留全部结果，不据性能挑选seed。
7. Full的训练探索期也记录信号频率。若评估和训练中都几乎没有外部责任，记录可辨别性不足；不自动增负载、缩DDL、降rho下限来制造差异。

## 6. 指标与统计口径

主要性能：总计算能耗J、ESP@90、批次可靠性达标率、两者联合达标率。所有批次的能耗均保留，失败低能耗不表述为有效节能。

- ESP@90：一批50工作流中至少45个按时的批次比例。
- Rel：一批50工作流全部达到R>=0.9的批次比例；不代表R=1。
- 每个模型先对20测试seed汇总，再分别报告三个训练重复；主表可给三个训练重复的均值及其样本SD，原始20seed内波动另存。不得把60个测试值当成60次独立训练。
- 配对比较以同训练seed、同工作负载seed进行；展示三个训练重复的效应方向和幅度。只有3次训练时不夸大显著性或稳定性结论。
- 连续诊断：归一化迟到及其尾部、排队等待、实际活动工作流数；不以平均DSR代替ESP。

归因诊断：每轮sum(d)、非零d比例、Full外部责任占总责任的比例、被影响工作流数、零边际回退频率、四乘子轨迹。分母为零的比例记为NA并同时报告零信号轮数，不当作0%外部影响。

训练开销：回放耗时、每轮总耗时、计算回放次数及其占比。不同组并发的墙钟时间不是隔离吞吐基准；如比较开销，使用同硬件、同资源限制的独立测量。反事实回放用于训练轨迹结束后的反馈，不计作部署时每次决策额外执行的操作。

可靠性若全部100%，按事实报告；本轮不能升级为“可靠性反馈独立有效”的证据。

## 7. 输出与结论边界

后续实现准备独立结果根目录，保存计划/配置/代码SHA、每轮输入表、训练日志、双验证与选模记录、checkpoint SHA、逐批CSV/JSONL、逐工作流记录及归因诊断。原始实验和论文不覆盖。

论文建议一张四版本性能表，按五个条件分别报告；三训练重复的训练曲线和外部责任/开销诊断可放附录。无需重跑已有HEFT/固定频率/无Deadline头实验。

- Full vs Self与Uniform跨重复改善：可支持所测场景中共享队列责任分配的作用。
- Self vs Raw改善：可支持所测预算下区分频率增量损失的作用。
- 只有Full vs Raw改善：仅能支持整套反馈方案，不能拆分两个因素。
- 若相当、反向、或外部影响几乎为零：如实报告，降低相应贡献强度；不无限追加候选和改变训练时长。
- 本设计不是完整2×3析因实验，不估计所有代价定义与分配方式之间的交互，也不检验上层/可靠性归因独立贡献。
