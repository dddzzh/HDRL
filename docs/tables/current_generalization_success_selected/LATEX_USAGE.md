# LaTeX 表格使用说明

- `full_results.tex`：3 张按 Loose / Medium / Tight 分块的完整表，覆盖 9 场景、4 算法、108 组。每种算法均有 Energy（J，均值和样本 SD）、ESP@90、可靠性达标率三列。成功率显示百分比与通过计数，例如 100% (20/20)。
- `scenario_results_and_text.tex`：9 张按场景分块的表，每张包含三档 Deadline、四算法及全部成功率，同时包含 9 段英文分析和总体限制说明。
- `table_preview.tex`：独立预览源，内嵌全部表格，供检查排版，不需要插入论文。

这两种正文展示方式基本覆盖同一组数值，建议选择一种作为正文，另一种放附录，避免把全部数字重复两次。

## 插入方式

导言区需要：

```latex
\usepackage{booktabs}
```

把相应 `.tex` 内容复制进论文正文，或将文件复制到论文项目中，再使用 `\input`。文件不包含 `\documentclass` 和 `\begin{document}`，适合直接插入 IEEE 双栏论文。使用 `table*` 跨双栏表格。能耗为两行显示：上行均值，下行为 ± 样本 SD，单位仍为 J。
