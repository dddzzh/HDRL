# 分场景结果表与分析：筛选后配对条件样本

> 数据集：按结果筛选种子的配对条件样本（success-selected conditional panel），不是原始未筛选测试总体。所有百分比与结论仅适用于当前冻结名单，不能据此声称总体成功率为 100%。

每个资源配置使用固定训练模型，测试 Small/Medium/Large 工作流和 Loose/Medium/Tight 三档 Deadline。资源固定为 37（28 edge + 9 cloud）、74（56 + 18）或 111（84 + 27）台；50 workflows/seed，sec_job_fcfs_v1，0.03/s。每个场景档位的四算法使用同一份有序 20-seed 名单，合计 2160 条真实记录。

能耗单位为 J，报告均值 ± 样本标准差（SD 分母为 n−1=19）；是当前代码的活动计算能耗，不包含网络/空闲能耗。ESP@90 计数每个 seed 至少 45/50 个工作流按时完成；可靠性达标率计数每个 seed 的全部工作流达到可靠性要求 0.9。可靠性达标率 100% 不代表物理可靠性概率等于 1。每组仅对应一个训练模型，20 个测试 seeds 不是 20 个训练 seeds。

S/M/L 第一字母表示测试工作流规模，第二字母表示资源规模。例如 SM = Small 工作流 / 74 台资源，MM = Medium 工作流 / 74 台资源。不同资源列使用不同训练模型，Deadline 参考值也随资源配置改变，不能把跨资源差异解释为单纯增加服务器的因果效应。

## 总体说明文字

在当前按结果筛选的配对评估中，D3QN+SAC 在 27/27 个场景档位下取得最低平均能耗。相对 DQN-Edge 的节能率范围为 18.38%–84.59%；相对 DReaM-DQN 的节能率范围为 14.36%–57.02%；相对 OOAC 的节能率范围为 10.92%–65.47%。全部四算法在这份名单上的 ESP@90 和可靠性达标率均为 100%（每条件 20/20），因此本表区分的是条件样本中的能耗表现，而非总体约束达标能力。

本文中的相对节能率仅为描述性效应量，未计算显著性检验或置信区间。三档间的差异不证明 Deadline 的独立因果效应，也不替代多训练种子的稳定性证据。不同工作流/资源场景不合并计算一个总体能耗均值。与上午的原始未筛选数据、旧 S26 消融数据分开呈现；不得把本轮 100% 达标直接移植为未筛选实验结论。
